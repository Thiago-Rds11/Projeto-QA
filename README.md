
🧪 Projeto QA — Sistema de Login
📌 Sobre o projeto

Este projeto foi desenvolvido durante meus estudos de QA e testes de software.

A ideia foi criar um sistema de login simples e usar esse sistema para praticar, na prática, algumas etapas do trabalho de QA: criar cenários de teste, executar os testes, analisar os resultados, identificar problemas, documentar bugs e realizar novos testes depois das correções.

O projeto também me ajudou a entender melhor como funciona o processo de encontrar e investigar problemas em uma aplicação.

🔎 O que foi testado

Foram criados testes para diferentes situações:

Campos de login vazios;
E-mail inválido;
Senha com menos de 6 caracteres;
Login com dados corretos;
Senha incorreta.

Os casos de teste completos estão disponíveis em:

📁 casos-de-testes/login.md

🐞 Bug encontrado

Durante os testes, encontrei um problema na validação do e-mail.

Ao informar um e-mail como teste@gmail, o sistema não identificava corretamente que o formato era inválido e apresentava a mensagem "Email ou senha incorretos."

O problema foi registrado como bug, corrigido no código e testado novamente.

O relatório completo pode ser encontrado em:

📁 bugs/bug-login.md

🔄 Processo utilizado

Neste projeto, segui um fluxo simples de testes:

Planejamento → Execução → Identificação do problema → Documentação → Correção → Reteste
